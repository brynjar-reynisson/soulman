# Diary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Diary page to the Soulman dashboard — accordion year → month → day → entries — backed by plain `.txt` files on the Google Drive for Desktop mount.

**Architecture:** New `web-svc/diary` package (filesystem only, validated args, sentinel errors) behind four owner-JWT routes in `web-svc/httpserver`, plus a React `DiaryPage` with a small reusable `Accordion`. Config adds `web.diary_root`. A one-off PowerShell script migrates the 10 existing entries to the new layout.

**Tech Stack:** Go (chi, stdlib `os`/`path/filepath`), React + TypeScript + Vite, Vitest + Testing Library, PowerShell.

**Spec:** `docs/superpowers/specs/2026-10-30-diary-design.md`

## Global Constraints

- Layout: `<diary_root>\<YYYY>\<MM>\<DD>\entry-<HH-MM-SS>.txt`, UTF-8, server-local time. `diary_root` = `G:\My Drive\diary`.
- Config key `web.diary_root` is required non-empty; existence on disk is NOT checked at startup. A missing root yields 503 per request.
- Routes (all behind the existing owner-JWT middleware): `GET /api/diary/tree`, `GET /api/diary/entries?date=YYYY-MM-DD`, `POST /api/diary/entries`, `PUT /api/diary/entries`.
- Errors → status: `ErrNotFound` 404, `ErrExists` 409, `ErrInvalidName` 400, `ErrRootUnavailable` 503.
- Tree and day listings: tree newest-first; a day's entries ascending by time.
- Empty/whitespace-only content on create → 400. Filename/timestamp never changes on edit. No delete, no search, no Dropbox.
- Frontend: view `'diary'` / `?page=diary`; "Diary" link directly right of "Projects" in `Dashboard`; accordion opens one section per level; open path in URL params `diaryYear`, `diaryMonth`, `diaryDay`; no auto-open of newest; month shown by name; inline message "Diary folder isn't reachable — is Google Drive running?" on 503. No new npm dependency; reuse existing Tailwind utility styling.
- Git: stay on `feature/diary`; `git add` every new file; commit messages end with the two attribution lines the session specifies.

## Review Focus

- Path traversal via `date`/`name` (`..`, slashes, backslashes, absolute) → `ErrInvalidName`, tested in Task 2 and 3.
- `diary_root` missing (Drive not mounted) → 503, not 500/crash, and web-svc still starts — Tasks 1, 2, 3.
- Two saves in the same second → second entry gets the next free second, first not overwritten — Task 2.
- Stray non-entry files/folders in the diary tree (e.g. `.tmp`, Drive `desktop.ini`, a non-numeric folder) are ignored, not errors — Task 2.
- Empty `diaryYear` URL state pointing at a year that no longer exists doesn't crash the page — Task 4.

### Task 2: `diary` package

**Files:**
- Create: `web-svc/diary/diary.go`
- Create: `web-svc/diary/diary_test.go`

**Interfaces:**
- Produces (package `diary`):
  - `var ErrNotFound, ErrExists, ErrInvalidName, ErrRootUnavailable error`
  - `type Day struct { Day string; Count int }`, `type Month struct { Month string; Days []Day }`, `type Year struct { Year string; Months []Month }`
  - `type Entry struct { Name string; Time string; Content string }` (`Time` = `"HH:MM:SS"`)
  - `func Tree(root string) ([]Year, error)` — years/months/days descending; only digit-named folders of widths 4/2/2; a day is listed only if it has ≥1 file matching `entry-HH-MM-SS.txt`; `Count` = number of such files. `ErrRootUnavailable` if `root` can't be read (not-exist or otherwise).
  - `func ListDay(root, date string) ([]Entry, error)` — `date` is `YYYY-MM-DD`; ascending by name; only matching filenames; `ErrInvalidName` for a malformed date, `ErrNotFound` if the day folder doesn't exist, `ErrRootUnavailable` if root missing.
  - `func Create(root, content string, now time.Time) (date string, e Entry, err error)` — `ErrInvalidName`-free; returns an error (`ErrEmptyContent`, also exported) for whitespace-only content; creates folders (`0o755`), writes with `os.O_EXCL`; on `os.IsExist` advances `now` by one second and retries (bounded, e.g. 60 tries, then `ErrExists`). `ErrRootUnavailable` if root missing — do NOT create the root itself.
  - `func Update(root, date, name, content string) error` — `ErrInvalidName` for malformed date or name not matching `entry-HH-MM-SS.txt` (this also blocks `..`, separators, absolute paths); `ErrNotFound` if file missing; overwrites in place.
